# yumeriablog.github.io

Personal blog at [blog.yumeria.dev](https://blog.yumeria.dev) — thoughts on things, stuff, and everything else.

Built with [Hugo](https://gohugo.io/), deployed on GitHub Pages.

## Features

- Dark-first theme with neon accent colours and light/auto variants
- Client-side full-text search
- Image galleries with lightbox overlay
- Mermaid.js diagram rendering
- Social media embeds (X/Twitter, Instagram)
- RSS feed

## Tech

| Layer       | Stack                          |
|-------------|--------------------------------|
| Generator   | Hugo 0.164.0                   |
| Hosting     | GitHub Pages                   |
| CSS         | Single minified stylesheet     |
| JavaScript  | Vanilla JS (no frameworks)     |

## Development

The Hugo source files (content, layouts, theme, config) live in a separate repository. This repo contains only the compiled static output.
